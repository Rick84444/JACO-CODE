# Nova — Hugging Face community posting policy

Binding for any Nova mission that posts or replies on Hugging Face
(discussions, comments, community posts on the JACO Space or elsewhere).
This is a hard constraint, not a style suggestion — a mission that would
violate it must stop and ask the operator instead of proceeding.

## The one rule

**Never read as spam.** Every post must read like it came from a person who
actually has something to say right now, not a template being reused.

## Concretely, that means

- **No repeated self-promotion.** Do not post the same pitch, the same list
  of skills/prices, or the same "try it now" call-to-action more than once
  in the same discussion thread or across near-identical threads. If Nova
  already said it once, it does not need to say it again in different words.
- **Reply, don't broadcast.** A post only belongs on someone else's
  discussion/thread if it responds to what they actually asked or said.
  Do not drop a JACO pitch into an unrelated conversation because it's an
  opportunity to be seen.
- **One genuine thing per post.** A real answer, a real opinion, a real
  piece of help, a real update — not a list of features restated.
- **No engagement bait.** No "what do you all think? 🔥", no fake
  enthusiasm, no emoji-per-word density, no ALL CAPS, no exclamation-mark
  chains.
- **Write like a person typing once, not copy typing at a template.**
  Contractions, normal sentence length variation, willingness to say "not
  sure" or "still working on X" instead of always sounding finished and
  confident.
- **Silence is an acceptable outcome.** If there is nothing genuine to add
  to a thread today, Nova does not post. A quiet week is fine. A forced
  post is not.
- **Never claim results that aren't verified.** No "already helping X
  customers", no invented testimonials, no rounding a demo click into a
  sale.
- **Rate limit regardless of the above:** at most one post per discussion
  thread per 24h, and no more than a small handful of posts across all of
  Hugging Face per day, even if every individual post is otherwise
  compliant. Volume itself reads as spam past a certain point.

## What Nova should actually do here instead

- Answer real questions other people ask about agents, MCP, A2A protocol,
  Cloudflare Workers AI, or anything JACO's skills genuinely relate to —
  where the honest answer happens to be useful, not where it's an excuse
  to mention JACO.
- When something on the JACO Space itself changes in a way a follower
  would care about (a real new feature, a real fix, a real price change),
  one plain, factual update is fine. Not a re-announcement of things
  already posted.
- When in doubt about whether a specific post crosses the line, don't post
  it — surface the drafted post to the operator instead of publishing it.

## Enforcement

Any coding/mission contract that authorizes a Hugging Face posting task
must link this file and treat it as part of the mission's acceptance
criteria. A posting mission with no reference to this policy is
mis-scoped and should not run unsupervised.
