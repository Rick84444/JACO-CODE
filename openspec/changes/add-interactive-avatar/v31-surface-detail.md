# V31 surface detail refinement

V31's visible hair is the exact material Aura V26 neutral platinum photo hair, using an 832x512 image with 13 vertical locks. The measured alpha fraction at the existing cutoff is about 79.5%; roughly 66.7% of the atlas is fully opaque. Hidden legacy hair and eyebrow masks are 2x2 transparent images and are not changed. The shader adds restrained longitudinal detail with derivative-based distance fade and reduces the visible photo hair alpha cutoff from 0.42 to 0.36. Alpha-to-coverage is enabled only with actual antialiasing support; depth writing remains enabled. This does not produce new strand geometry or fix card layout.

Skin uses a bounded per-channel wrapped direct diffuse response to soften the light terminator while preserving the original textures and specular response. This is a real-time approximation, not volumetric or screen-space subsurface scattering. Patch anchors match the pinned Three r186 source. If an anchor changes, retain the original shader. No extra pass or external texture is introduced. Validate actual shader compilation, hairline/edge AA, no halos, skin tone and mobile performance with the original GLB. The local visual proxy is not the browser shader output. Actual eyelid geometry, tear line, mouth anatomy and planar floor reflections remain separate work.
