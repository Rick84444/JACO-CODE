# Design
Reviewed provider: https://mcp.linear.app/mcp. Linear documents scope read as enforced read-only; its live public RFC8414 metadata at https://mcp.linear.app/.well-known/oauth-authorization-server advertises issuer https://mcp.linear.app, /authorize, /token, /register, public clients, S256, authorization code and refresh. Sources https://linear.app/docs/mcp and https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization . Protected resource metadata was not retrievable in research; runtime must verify resource and issuer before registration, fail closed if unavailable. Pin exact endpoints, no redirects, read scope only, state and issuer checked, loopback callback, one-time attempt, bounded response and expiry. DCR only for provider explicitly supporting it. No arbitrary issuer, borrowed client ID, secret in GUI, automatic replay or capability grant. Compare official SDK v2 versus narrow dependency-free adapter; use narrow adapter for first isolated pilot to avoid changing legacy HTTP transport. Need later review of CIMD and provider live acceptance. Tokens returned only to an internal caller; this stage does not persist or attach them. No claim of production readiness.

## Stage 2: credential lifecycle and canonical transport
Reserve JACO_MCP_OAUTH_LINEAR as an encrypted, non-exportable session record (not an environment bearer). Bind it to linear and the exact reviewed MCP resource. Initial authorization alone is insufficient: require an internal get_user(query: me) read probe with advertised read-only schema and account-shaped response before persisting and creating a read-only host configuration. The exact tool contract remains subject to live certification. Serialize refresh by atomically replacing the current encrypted session with a durable refresh-in-progress marker before the network call. On lost outcome, fail closed and require operator reauthorization, never retry a potentially consumed refresh token. Persist rotated credentials before issuing subsequent requests; no automatic replay of MCP calls. Reauthorization/remote revocation and UI wiring remain separate steps. Reject generic vault get/save for this namespace; not an isolation boundary against arbitrary shell access. No silent replacement of an existing configured Linear server.
