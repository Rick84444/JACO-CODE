# Design

One explicit local operator action validates a fixed provider ID and credential against the reviewed MCP endpoint using the canonical HttpMcpClient. A connection is not verified until an allowlisted read-only tool call returns without an MCP error; discover tools first and refuse missing/unsafe probe schemas. Never send a provider credential to an arbitrary endpoint. Persist a scoped, non-exported SecretStore credential only after proof and configure the canonical host; recheck configuration before committing. Keep existing connections unchanged unless a separate explicit repair flow is implemented. No OAuth impersonation or arbitrary login URLs. Distinguish probe result from real-world business outcome. Official references: https://render.com/docs/mcp-server ; https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/customize-copilot/extend-copilot-with-tools-and-context/set-up-the-github-mcp-server ; https://github.com/github/github-mcp-server .

## Credential lifecycle
An HTTP 401/403 or missing credential invalidates the current MCP session; no replay of dispatched calls. Guided credential replacement is an explicit local operator action, restricted to an already scoped, read-only connector. Validate the candidate in a disposable session before changing the vault; compare-and-set prevents overwriting a concurrently changed credential. Retire the existing session and clear per-connection evidence without changing the saved endpoint, deny list or access settings. Do not silently rotate legacy environment references or write-enabled connectors. The operator must explicitly acknowledge that the replacement can change account identity and must recheck workspace/repository scope. Scoped credentials are rejected by the ordinary agent vault get/save helper; this does not provide isolation against arbitrary host shell access.
