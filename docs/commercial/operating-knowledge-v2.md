# Commercial operating knowledge — v2

This is reusable procedural knowledge, not a claim that JACO has paying users or exceeds other agents. Canonical runtime memory is seeded by the existing commercial clock under `commercial-operator-knowledge-v2`; the text here expands its source rationale. Do not create another memory database.

| Knowledge | Decision rule | Falsifier |
|---|---|---|
| Demand before building | One verifiable buyer pain and a testable deliverable precede speculative product work | Buyer already uses an adequate free tool or refuses the proposed outcome |
| Time to value | Optimize the first external successful task, then repeat use | Fresh installation or first task fails |
| Technical differentiation | Compare same task/model/budget and independent test oracle | Alternative performs as well or better; narrow the claim |
| Distribution fit | Reach people already experiencing the problem and follow channel rules | No eligible responses or channel disallows promotion |
| Service outcome | Sell a bounded, accepted result, not generic AI capability | No acceptance criteria or buyer permission |
| Cash discipline | Compare probability-adjusted net contribution, effort, fees, time to collection and downside | Unknown cost, uncollectible reward or poor contribution |
| Learning | Record observed outcome, evidence ID, decision, uncertainty and next change | Claim cannot be linked to an observed receipt |

## Evidence classes
Public signal, hypothesis, observed tool receipt, independently verified acceptance, settlement. Do not promote between classes based on model confidence. Store failure observations and counterexamples. Never commit secrets or actual customer data to the public repository.
