# Design

The existing `cloud/control/handoff.mjs` owns admission, state transitions and receipts; `postgres-store.mjs` and migration own durable cloud handoff persistence. The local Aura mission ledger remains authoritative. Existing JACO Link is the transport reference. The merged remote PWA and MCP Workbench are not replaced. Provider OAuth onboarding (PR #412/#414) is distinct from customer JACO Cloud identity delegation; share reviewed components where compatible, not credentials or trust domains. No external mutation route is exposed until trusted identity, paired device authorization, revocation, dispatch fencing and evidence verification exist. Existing Render services are not implicitly repurposed. Compare this isolated source transplant against direct merge of divergent PR #355; require exact tests and real PostgreSQL concurrency/restart checks before deployment.
