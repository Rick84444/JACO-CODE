# Economic Governor

Cloud reasoning is **default deny**. The governor tracks reservations, actual settlement and verified revenue independently of model prompts.

Policies include daily, monthly and per-task hard limits. A model router must reserve estimated cost before a cloud call. If the reservation cannot be made, the cloud call is refused. Local Ollama remains available without a cloud token budget.

Financial commitment, payment, credential change, permission escalation, destructive actions and public publishing are high-consequence operations and require an operator checkpoint when executed under a lease.
