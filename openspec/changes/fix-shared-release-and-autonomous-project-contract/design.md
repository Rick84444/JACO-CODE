# Design
One source owner per responsibility: gateway/src/seer-project.mjs owns generated project tickets, NovaMissionControl owns leases and failure limits, approval-policy and claim-check own resolution, and the existing workflows own artifact builds. Lite delegates to the same contract generator instead of overriding fields. Windows packaging records the source commit from checkout. Both release jobs remain independently tested; public release promotion is unchanged and separately authorized.
A longer recovery allowance applies only to distinct known failures within the existing autonomous contract; repeated identical action, policy, spend, uncertain effect, and exhausted budgets remain hard boundaries. Claim checks retain rule evidence and use one bounded provider deadline for the Core mission-review path; provider absence is reported, not simulated as model judgment. Existing explicit verification requirements remain.
