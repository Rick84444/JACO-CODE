## Design
H0: the existing rig renderer can present a texture-preserving mesh without a second behavior or voice engine. Reuse its rig validation, morph assignment, body motion, hidden-tab/reduced-motion lifecycle and adaptive rendering budget. Add an explicit anatomical candidate mode with neutral studio lighting and full-body framing. No point cloud or cavern material replacement in this mode. Keep existing modes selectable until independent acceptance. No automatic external download, new model, microphone permission, server API or new agent. Local operator-provided GLB goes in ignored runtime/public/branding/aura-anatomical.glb; installer checks exact candidate size and SHA-256 before copying. Asset not committed or automatically distributed. Runtime checks exact size and hash where secure Web Crypto is available; reject mismatches. Do not silently substitute the old model. Render the original GLB's materials, not invented procedural skin. Use its actual measured dimensions for camera framing. Dispose texture resources as well as geometry and materials on exit.

## Operator Stage integration (2026-11-28)
The start page shows the installed anatomical model as the whole figure (operator request) and keeps the lightform in the centred layout when no verified model is installed. The stage serves every module the rig imports; textures load as image elements so the page's `connect-src 'self'` stays unchanged; the full-body camera is fitted to the measured figure; the textured figure is antialiased and never drawn below one buffer pixel per CSS pixel.

Observed on Windows 11 (Chrome headless, AMD integrated GPU, D3D11) with the operator's V31-JACO file (45304080 bytes, matching the pinned SHA-256): whole textured figure at 1920x1080, 1600x900, 1280x720, 900x900 and with the IDE beside; first figure after about 11 s (one run 29 s); no horizontal overflow. Not observed: lip movement with real speech, sustained frame rate and resource use during a mission, other GPUs, Android. Visual acceptance by the operator is open. The face, hair and suit colours differ from the operator's reference image; those come from the model file.
