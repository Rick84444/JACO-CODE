Agenternas kognitiva kapslar

01 / Intent

User Agent

Äger problembeskrivning och objektiva kriterier. Kan inte ändra kod eller godkänna egna krav.

02 / Build

Developer Agent

Föreslår strategi, konsulterar verifierat minne och begär granskning. Kan inte certifiera egen kod.

03 / Verify

Reviewer Agent

Kör HTTP-baserade kontraktstester i separat Node-process. Först efter PASS kan den främja en skill.

Vad resultatet betyder – och inte betyder

[REAL] Kod, HTTP-anrop, tester, minnesåterhämtning, begränsade agentbehörigheter och lagring kördes på riktigt.
[SIMULATED] Agenternas resonemang och kandidatval är fördefinierad programlogik, inte tre språkmodeller.
[LIMIT] Detta mäter färre strategiförsök vid ett återkommande problem. Det bevisar inte generell intelligens, produktionssäker exekvering eller lärande på nya okända uppgifter.
