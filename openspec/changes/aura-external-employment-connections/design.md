# Design

Reuse existing stdio/HTTP MCP host, safe public HTTPS fetcher, credential discovery and legacy skill catalog. Jobbi is the read-only index; AgentGigs uses a dedicated worker-side adapter with a locally configured key, explicit write flag and existing mcp-write mission authority. Application attempts are journaled before mutation; unknown outcomes are never replayed. Public API discovery emits bounded metadata only, with CDP as a documented existing-tool fallback. No credential harvesting or arbitrary authenticated endpoints. Official contracts: https://jobbi.org/docs/mcp/ and https://www.agentgigs.io/docs/api. Negative controls: no write flag, duplicate/ambiguous application, private URL, truncated/cross-origin spec. Verification: node --test tests/nova/agentgigs-mcp.test.mjs tests/nova/public-api-discovery.test.mjs tests/nova/mcp-host.test.mjs tests/nova/skills.test.mjs; full canonical CI. Live authenticated provider/Windows evidence is separate and not claimed.
