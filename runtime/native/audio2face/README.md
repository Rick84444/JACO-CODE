# Optional NVIDIA Audio2Face local engine — experimental
Pinned SDK commit: 1ca0f02535ed774f5dbcd724a31cd486368dc783 (MIT). Model terms are separate: https://huggingface.co/nvidia/Audio2Face-3D-v3.0 . NVIDIA documents Windows 10/11, CUDA >=12.8 <13, TensorRT >=10.13 <11, 4 GB VRAM recommended and 10 GB disk. Verify the actual GPU and model requirements first. Do not download models on behalf of the operator without accepting applicable terms through their own account.

The C++ bridge uses the public host blendshape executor, obtains exact pose names from the skin solver, emits one JACO_A2F_JSON: line of timestamped weights (SDK timestamps are audio sample indexes). No mesh replacement, no external API. This is a per-utterance process proof of integration, not persistent streaming inference. SDK initialization cost may be too high; HeadAudio always remains available.

## Build on the Windows trial checkout
Clone https://github.com/NVIDIA/Audio2Face-3D-SDK.git in a separate directory, checkout the pinned commit, follow upstream README for git-lfs, build tools, CUDA/TensorRT and model generation. Copy this directory into SDK audio2face-sdk/source/samples/jaco-a2f and add `add_subdirectory(jaco-a2f)` to the SDK samples CMakeLists.txt. Build the jaco-a2f target through the upstream build. Use the SDK-generated model.json for the selected regression or diffusion blendshape bundle, not a raw ONNX file. Check SDK build and runtime DLL paths. Native build and GPU inference are NOT verified by JACO CI.

Set in the approved local runtime environment:
- JACO_A2F_ENABLED=1
- JACO_A2F_EXECUTABLE=absolute path to jaco-a2f.exe
- JACO_A2F_MODEL_JSON=absolute path to generated model.json
- JACO_A2F_MODEL_KIND=regression (default) or diffusion

The same-origin loopback endpoint accepts only bounded decoded mono 16kHz speech PCM generated by the existing TTS pipeline, no mic, no remote access. One process at a time, max 20s clip, server timeout 8s, client timeout 4.5s, no shell or user-provided executable path. The default remains HeadAudio, no extra dependencies installed on ordinary JACO. The health endpoint reports configured executable/model availability, not verified GPU readiness; only validated output sets the NVIDIA playback status. Late neural data blends in on the media clock; gaze/brows/eyelids remain with existing director. Test actual morph correspondence, gain, timing, real Swedish recordings, device FPS, cold/warm startup, fallback and interruption. Never claim NVIDIA is installed from the presence of the source.
