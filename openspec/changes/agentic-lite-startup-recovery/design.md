# Design

Observe ledger lock and Linux process identity (host, boot ID, start ticks, UID, workspace, exact packaged server argument) plus the corresponding install/launcher identity. Only a proven same-workspace Lite process is eligible. Non-Linux/ambiguous owners fail closed. A healthy requested-port instance is reusable only with owned listening socket and exact release/GUI evidence. Recheck identity and ownership before signalling a supervisor (or PID 1-reparented orphan); use SIGTERM only, wait bounded time for confirmed writer exit and free port, then let the ledger's existing lock acquisition handle stale locks. Explicit --recover permits graceful restart, not repeated mutations. Default strict port prevents silent drift; explicit --port remains supported. Preflight is read-only. Record classified results as lifecycle receipts without secrets.

Acceptance: a real old same-project owned writer is diagnosed before spawning; ambiguous owners get no signal; successful handoff preserves ledger bytes; explicit busy unrelated port is not reclaimed; a successful existing attachment is verified; no SIGKILL or lock deletion. Test with fixtures and CI; physical Pixel acceptance remains separate.
