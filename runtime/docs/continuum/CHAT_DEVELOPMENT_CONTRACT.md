# JACO Cognitive Runtime — Chat & Development Contract

## Root authority
Rick is the final operator. Operator override, pause, emergency stop, permission revocation, budget revocation and rollback outrank every planner, model, agent, skill and tool.

## Runtime, not prompt, owns autonomy
JACO persists goals, commitments, evidence, budgets, agent state and recovery information. Models are replaceable reasoning compute. A chat session is never treated as the durable scheduler.

## Preserve before replace
A new candidate must be built and tested in parallel. The candidate scripts use **3020/3299/3298** and do not modify the canonical Termux `runtime.env`. Promotion is a separate operator action with rollback.

## Evidence before claims
Implemented, statically verified, runtime verified, integration verified and production proven are distinct states. A task cannot become fulfilled merely because a model says it is complete. Evidence is attached to state transitions.

## Cognitive Continuum
The release provides Mission Capsules, Commitment Graph, Execution Leases, Evidence Ledger, Runtime Hub, persistent scheduler, Hypothesis Engine, Capability Compiler, Cognitive Compression, Browser/CDP Runtime and Economic Governor.

## Browser runtime
CDP is the browser transport. JACO exposes stable semantic browser operations, not raw CDP as the contract for planners. Observations are compressed into semantic state and deltas. Batches are bounded by confidence, leases, stop conditions and consequence class.

## Economic safety
Cloud reasoning is default-deny. Financial commitments require explicit operator approval. Budgets are hard caps, not prompt suggestions. Revenue is credited only with evidence.

## Continuous improvement
Verified trajectories may become capabilities only after repeated successful evidence. Capabilities are versioned and promoted separately. Self-modification never bypasses release verification.

## Runtime Hub
Agents communicate through structured messages, tasks, evidence refs and state refs. Registration does not imply unrestricted permission. A2A inbound work enters the Hub as submitted work, not completed work.

## Truth boundary
This source package can be build- and container-tested here. Android/Windows/CDP production status must be established by target-machine evidence after installation.
