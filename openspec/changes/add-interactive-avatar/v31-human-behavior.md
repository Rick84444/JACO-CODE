# V31 human behavior and motion fusion

One presentation director combines live conversational state, actual audio level, and the bounded existing stage presentation cues. Listening has priority; explicit panel focus precedes thinking glances; head follows gaze; speech onsets trigger rate-limited brow, nod and hand beats. Idle has breathing and subtle stance variation, not simulated speaking. Hair uses damped head-motion lag, not a physics claim. The actual GLB rest skeleton contains 30 finger bones; curl axes are inferred from authored segment curvature and rotation is bounded around the original pose. Hip offsets use stage metres and support-side shifts before foot lift. Existing V31 asset, materials, voice and default camera are preserved. No new tool authority or agent is created.

Motion source candidates for later A/B evaluation: Quaternius Universal Animation Library (CC0) and KinemIQ free CC0 repack; ACCAD and 100STYLE attribution-licensed recordings require per-clip review.
