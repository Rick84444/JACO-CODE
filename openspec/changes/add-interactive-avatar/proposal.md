# Add interactive avatar
## Why
Keep the existing chat and compact terminal unobstructed during execution; present a lifelike particle-based female avatar only on operator request or meaningful communication.
## Scope
Extend canonical React UI for Windows and Android Remote. Reuse existing voice and mission services. No separate runtime, planner or mission store.
## Acceptance
Opening and closing the avatar does not interrupt a mission. Actual speech drives facial animation. Unsupported graphics fall back to chat. Falsifier: any mission cancellation, fabricated status, or audio-only amplitude presented as phoneme lip sync.
