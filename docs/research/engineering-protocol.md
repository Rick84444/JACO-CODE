# Evidence-first engineering protocol

For each bounded task: inspect canonical code and current main; define acceptance criteria and baselines; inspect upstream algorithms and licenses; challenge assumptions; implement the smallest compatible change; execute actual tests; repair and rerun; inspect integration diff and CI; commit and report exact evidence. Prefer working code over additional planning documents. Distill failed mechanisms rather than accumulating complexity. Never claim tests ran without execution receipts, or claim a commit landed without confirmation. Record blockers and remaining work precisely. Keep experimental work disabled by default, preserve existing authorization boundaries and never merge research without operator approval. Stop at verified acceptance or explicit resource/blocker limits; do not hide incomplete work. This is a repository working protocol, not a modification of any model's system prompt.
