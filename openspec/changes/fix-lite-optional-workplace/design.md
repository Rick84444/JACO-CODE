# Design

Use the existing Lite launcher and session contract, not a new runtime. The bundled server and Nova continue to use the existing generated local runtime credential. Local Workplace registration is attempted first and remains available for coordination; if startup fails in optional mode, the launcher reports degraded status, stops its own failed child, and continues local work without claiming a session. Explicit JACO_WORKPLACE_REQUIRED=1 retains strict startup. A remote or shared operation must still satisfy its own authorization, session and mission requirements. The chosen port is passed to children so health does not probe an unrelated default listener. The health projection uses its existing NOT_SUPERVISED vocabulary for optional absent Lite services. No new token, service, remote endpoint, or approval policy.
