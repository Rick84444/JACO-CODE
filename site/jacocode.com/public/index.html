    How it works

    1. Plan with your model. Ollama, Groq, DeepSeek or any OpenAI-compatible endpoint. JACO keeps the model inside a contract: allowed tools, budgets, approvals.
    2. Act with real tools. Files, git, MCP servers and your own browser through CDP. Each step is a mission action with a lease, not a chat message.
    3. Prove it. Every action leaves a receipt. A separate model checks the final answer claim by claim against those receipts, and an answer that does not hold is sent back.

    JACO Lite

    The whole IDE and the Nova agent as one folder on your computer. Free. One command starts it, and nothing runs in our cloud.

    Your model, any model

    Paste an API key, or point it at Ollama or LM Studio on your machine. JACO finds out what it is and checks it. No account with us.

    An agent that has to prove it

    Give Nova a goal. It works on a separate git branch, never pushes or merges, and does not report done until your project’s own tests pass.

    Your code stays yours

    The server listens on your computer only. Keys are kept encrypted outside your project. Spending has a limit that you set.

    Download JACO Lite (zip, about 17 MB) SHA-256

    1. Install Node.js 22.5 or newer if it is not already on your computer.
    2. On Windows, right-click jaco-lite.zip and choose Extract All. Open the extracted folder.
    3. Double-click START.cmd in that folder, or run node start.mjs from a terminal there.
    4. The connection guide opens automatically. Connect your model, optionally configure Codex, Claude Code or VS Code, and test the JACO Editor tool.

    Extract the whole ZIP before starting. Running START.cmd inside the ZIP only unpacks the launcher, leaving the application files behind.

    Tested on Windows. Built and checked end to end in a clean folder, with a real goal and the project’s own tests passing.

    JacoCloud

    Your own JACO, reachable from your phone. Pair a browser with a one-time code from the IDE on your computer, install it to the home screen, and follow or start missions from anywhere. Keys stay on your machine, every device can be revoked, and the terminal never leaves your desk.
