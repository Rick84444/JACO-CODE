# Design

Use the existing mandate store, HypothesisEngine, KnowledgeStore and learning tick. Preserve valid existing mandates and initial operator-configured bootstrap; do not regenerate grants on a corrupt store. Normalize criteria over complete eligible candidates (relative min/max); zero weights are ignored; require finite metrics on positive-weight criteria. For no criteria retain evidence-based selection. Implicit selection considers verified evidence only. Explicit selection may select another eligible candidate with evidence. Search all records before applying the result limit, with deterministic ranking. Archive commercial outcomes independently of the learned marker using bounded retry batches; no new permission or execution paths. Falsifiers: expiry changes on restart; unit rescaling flips ranking; missing metric wins; old matching item disappears; archive failure prevents independent mission processing or becomes permanently marked complete. Relative scores are not calibrated probabilities; no claim of cognitive improvement without paired live trials.
