Get started without editing configuration files.

JACO starts the local services for you. Then choose the connections you want to use.

1. Your local installation

Checking the installation…

Open the IDE and connect a model

Do you already have model keys in the project's .env?

Choose a file below if you want to import known model keys into JACO's encrypted store. No values are shown in the chat. Other keys and existing stored keys are left untouched.

2. Connect your AI tool

Optional. You only need to connect tools you use. Claude Code and VS Code are configured in the project; Codex is configured for your user account. Existing settings are saved with a backup. Existing JACO entries are not changed automatically.

After saving: open the same project in the client and reload its MCP connections. The client may need your approval.

The test reads project information. It changes no project files.

3. Mobile and JacoCloud

Checking the address…

Open your installation's sign-in

Create a one-time code under Devices in the IDE and enter the code on the other device. The computer must be on and JACO running. Local MCP and model connections work without Cloud.

If you have no public address, you need your own authenticated remote connection. The guide does not open your computer to the internet automatically.
