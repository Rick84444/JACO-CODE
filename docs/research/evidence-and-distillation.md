# Evidence and cognitive distillation

Research protocol v0.1 — not validated implementation.

Preserve source episodes subject to operator retention/deletion policy. Derived memories must carry provenance, applicability conditions, counterexamples, version and rollback reference. Never recursively overwrite source evidence. Compare episodic-only retrieval with selective consolidation, forced consolidation, and existing runtime at matched model/tool/time/token budgets. Use held-out tasks, repeated seeds, independent outcome evaluators, report uncertainty intervals and failures. Measure success, transfer, calibration (Brier score), token/time cost, memory growth and contract violations. Test causal dependence by removing or substituting retrieved memories. Reject unhelpful components and retest simplified candidates. No automatic production promotion. No authorization changes by learned behavior. Use existing runtime integration points only; inspect actual code before implementation.

Evidence-sensitive dissent: assess independently before seeing operator advice where feasible; update according to source reliability and external evidence, not agreement or disagreement itself. Separate aesthetic geometry from correctness; temporal Hz only for real timestamped periodic signals. Test symmetry and spectral features as optional ablations, not acceptance criteria.
