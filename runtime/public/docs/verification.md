# Verification & Reality Classification Tags

JACO uses standardized reality classification tags across all output logs, status pages, and documentation to distinguish verified functionality from prototypes or design specs.

## Reality Classification Schema

- **`[REAL]`**: Functionality backed by live code, active process execution, or verified filesystem outputs.
- **`[PROTOTYPE]`**: Working or partially working feature under active iteration.
- **`[SIMULATED]`**: Behavioral UI mock or placeholder response for testing layout and workflows.
- **`[SPEC]`**: Architectural plan or design specification for planned features.
- **`[RISK]`**: Unverified or fragile boundary condition requiring caution.
- **`[UNKNOWN]`**: Inadequate data or telemetry to confirm system state.
