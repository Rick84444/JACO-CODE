2026-11-27. Operator approved reuse of mature licensed source instead of writing new algorithms. Baseline 183cc6a8c0ca9028c5de4915fd33dfc600661ef0. Current renderer applies only four vowel shapes and jaw; preserve existing voice ownership and conversation controller.
## Source and decision
HeadAudio https://github.com/met4citizen/HeadAudio/tree/9f7654914559cf3beaf731117d2efa91958ef640: MIT copyright 2025 Mika Suominen, verified LICENSE and dependency imports of nine JS modules. Vendor complete unmodified source modules, with full notice, not demo or training data. Browser AudioWorklet MFCC/Gaussian classifier with fifteen Oculus visemes, no extra service. Pretrained example uses English voices; no Swedish accuracy claim. Do not distribute pretrained weights without explicit asset rights review; locally provision a rights-cleared compatible model, no automatic download. TalkingHead https://github.com/met4citizen/TalkingHead/tree/1563de184c19b310de4b636664d5835e2c74dbba: MIT code, separate asset terms, no Swedish rule module at this revision. Do not import its full renderer/audio ownership or English rules as Swedish. Existing MPFB source asset from that project is already used. Evaluate its motion modules separately.
## Hypothesis and design
H0 existing formant tracker is sufficient; H1 HeadAudio improves phoneme distinction, especially closure and fricatives, without a second voice/render pipeline. Integrate an optional local model path in anatomical mode only; feed captured playback branch, never microphone or external destination. Source/clock lifecycles fence stale callbacks. No audio delay, no per-frame inference outside upstream worklet. If model missing/invalid or worklet unavailable, existing audio-formant path remains explicitly labeled. Explicit timed phonemes remain priority. Bind all 15 existing named viseme morphs, avoid double jaw driving; fail back when rig missing channels. Stop/clear on source detach, hidden/reduced motion and disposal. Validate model record size, finite parameters, valid IDs, nonempty class coverage; require local model provenance before production. Model path excluded from Git. 
## Acceptance
Compare same real audio and rig with and without module, hold identity constant. Verify 15 morph channels, silence, cancellation, stale events, pause/resume, malformed model rejection, missing model fallback, actual audio playback unchanged, no duplicate render/voice pipeline. Browser worklet and Swedish held-out utterances require actual observation, not simulated success; existing >=24/15 FPS and <=5% throughput loss targets remain. No merge until exact head CI, visual/physical acceptance and conflict resolution. No paid services.
