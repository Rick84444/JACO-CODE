# Design

One explicit local operator action validates a fixed provider ID and credential against the reviewed MCP endpoint using the canonical HttpMcpClient. A connection is not verified until an allowlisted read-only tool call returns without an MCP error; discover tools first and refuse missing/unsafe probe schemas. Never send a provider credential to an arbitrary endpoint. Persist a scoped, non-exported SecretStore credential only after proof and configure the canonical host; recheck configuration before committing. Keep existing connections unchanged unless a separate explicit repair flow is implemented. No OAuth impersonation or arbitrary login URLs. Distinguish probe result from real-world business outcome.
