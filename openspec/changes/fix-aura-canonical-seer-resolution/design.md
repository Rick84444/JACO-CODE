# Design
Operator -> Aura Core -> existing strategy adapter (SEER), durable execution adapter (Nova), evidence and review. The core resolver reads the current graph through its authenticated GET route, checks exact child identity, and applies the existing operator policy. The existing Nova resolve API rejects the legacy SEER authority; the internal resolver records Aura without minting manual approval or resetting budgets. Keep context window 40; use the indexed durable event rows and legacy session receipts for authority. Replans inherit the original contract and divide only the remaining used allocation; never treat an approval request as a strategy error.
