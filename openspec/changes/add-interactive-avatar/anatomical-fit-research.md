# Anatomical reconstruction: research decision, 2026-11-26
Follow-up to photo-rig-lod-evidence.md and digital-human-reconstruction-research.md. V2 is a useful skinning/LOD benchmark, not a suitable anatomical template. The next experiment replaces its estimated silhouette depth instead of increasing its polygon count. Preserve the approved photographic character and dark neutral background. No paid compute, no additional runtime agents, no new mic permissions. Research only; the following packages have not been executed or installed.

## Source-backed candidates
- https://github.com/VGCLUB/facefit-mpfb : GPL-3.0-or-later offline authoring prototype using MediaPipe landmarks, MPFB morph fitting, regularized optimization, UV projection, and a weak monocular depth prior. README reports CPU testing and acknowledges that front-photo texture biases landmark evaluation and profile depth is unresolved. Small project; pin reviewed revision, audit all models (including face parsing weights), isolate loopback bridge, and reproduce from original sources before reuse. No production guarantee.
- https://github.com/makehumancommunity/mpfb-mcp : official community repository, early beta, GPL-3.0, closed named-command vocabulary. README lists target and material editing, rig/IK/hand controls, mesh intersections, weight audits, asset licenses, and export copies with ARKit/visemes. Use as an optional offline authoring tool only, not a shipping MCP dependency or extra agent; limit local permissions and no arbitrary remote execution. 
- https://github.com/makehumancommunity/mpfb2/blob/master/LICENSE.md : GPL authoring code, core base meshes/targets and assets CC0; audit optional packs individually.
- https://github.com/met4citizen/TalkingHead/blob/main/blender/MPFB/MPFB.md : documented export-copy pipeline with Meta visemes and ARKit face units, custom rig, GameEngine PBR and glTF. Bake identity modeling keys, retain expression keys; bone axes, teeth motion and eyelash blinks require verification. Existing JACO compatible rig remains fallback.
- https://github.com/microsoft/TRELLIS.2 : MIT reconstruction candidate, upstream requires NVIDIA GPU with >=24GB memory. Offline comparator only, cannot assume user hardware supports it. https://github.com/SiTH-Diffusion/SiTH and https://research.nvidia.com/labs/dair/dream-lift-animate/ illustrate human-specific shape priors and novel-view generation, but these views are inferred. https://smpl-x.is.tue.mpg.de/modellicense.html explicitly limits the default SMPL-X license to noncommercial uses; reject shipping any dependency or generated derivative unless commercial rights are established.
- https://mfa-models.readthedocs.io/en/latest/acoustic/Swedish/Swedish%20MFA%20acoustic%20model%20v3_0_0.html and https://mfa-models.readthedocs.io/en/latest/g2p/Swedish/Swedish%20MFA%20G2P%20model%20v3_0_0.html : Swedish alignment and G2P weights CC BY 4.0, suitable candidates for recorded text/audio timing reference; verify dictionaries and notices separately. MFA is not a streaming system. https://github.com/met4citizen/HeadAudio browser AudioWorklet candidate, example pretrained model English; evaluate Swedish and audit code/weights. https://github.com/DanielSWolf/rhubarb-lip-sync recorded phonetic fallback with limited non-English recognition. Prefer actual provider viseme timestamps if available. Preserve existing audio playback clock.
- https://threejs.org/docs/pages/GLTFLoader.html : meshopt and KTX2 loaders supported with local decoders; no dependency or runtime change in this research step.

## Proposed experiment order
1. Freeze selected reference SHA and separate original from generated novel views. Acquire same neutral pose side/three-quarter head and body references; do not treat synthetic pictures as calibrated observations. Mark uncertainty, use 2D landmark/silhouette checks, reserve held-out angles. Fit head and body on MPFB anatomically valid topology, camera alignment before shape, regularize changes; separate hair, clothing, teeth, tongue and eyes. Compare untextured clay at front, 45, 90 and rear before photo projection. Measure errors normalized by interpupillary distance, but no automatic likeness pass from front texture or from synthetic landmarks alone. Operator blind side-by-side ratings. 
2. Project only visible skin/garment regions via occlusion-tested camera projection into UV atlas; use view-angle weighting, masks and seam blending. Unobserved regions get explicitly authored material, not stretched front color. Remove baked directional light where feasible; separate albedo, normal, roughness, metallic and emissive maps. Separate hair cap and cards with shared textures, 4–8 secondary bones as initial design budget, check head turns against collar/clothing. Build opaque garment mesh, not a recolored naked body. 
3. Preserve topology around mouth, eyelids and joints. Export identity baked separately from expression keys; verify bilateral blink, jawOpen, bilabial closure and required viseme targets, synchronized teeth/tongue/cheeks. Test hand poses and foot contact in standing clips, no sliding, no visible skin/cloth intersections. Use existing runtime state and GPU skinning. 
4. Compare provider viseme timestamps, offline Swedish MFA mapped to viseme IDs, and audio-only fallback using same 20 Swedish utterances plus 10 English. Include bilabials, rounded vowels (y/u/ö), fricatives, silence and interruption. Time against audio playback clock; measure median/p95 timing offset, preparation delay and dropped frames. MFA is an offline reference, not a new inference call per frame; no fabricated timestamps. Hold mouth neutral when no reliable audio/timing. 
5. Produce actual artifact previews: clay and textured four-angle renders, facial expression sheet, and short continuous gesture/speech video. Compare to V2 using same camera and approved image; target >=8/10 operator-rated with no critical region below 7, not a self-reported score. Start 30–60k triangles, 2K selective textures, compressed formats only after browser decoder support verified. Test hidden rendering off and model throughput loss <=5% against no-avatar baseline on real hardware. No claim measured yet.
6. Only after license, geometry, animation and resource checks pass, bundle versioned GLB with hash/manifest and fallback in existing Aura portrait. Do not merge V2 silhouette mesh as final. No installation, model generation or new benchmark performed in this research commit.
