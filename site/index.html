AI agents you can check, not just trust.

JACO is a local-first runtime that runs agents on your own machine. The model is replaceable. JACO keeps the goals, tools, policy, state and receipts, so you can see what was actually done.

How a run works

Every run follows the same path. JACO does not treat generated text, an attempted action or a successful network call as proof that the intended result happened.

  1. Goal
  2. Plan
  3. Bounded tool execution
  4. Observed result
  5. Verification
  6. Receipt
  7. Durable state

What it guarantees

Runs on your machine

Local-first. You connect the models you want to use; JACO owns the state around them, and it survives a restart.

Policy, not prompts

What a tool may do is decided by runtime policy, not by what the model says it may do.

Fails closed

If the outcome of an action is unknown, JACO stops instead of repeating it blindly.

Proof of work

A claim of completion needs a receipt or other observable evidence.

You approve the money

External financial commitments always need your explicit approval.

Secrets stay out of sight

Secrets are kept outside model-visible output and outside committed source.

Get started

You need Node.js 24 or newer. Clone the repository, then:

npm run setup
npm run jaco:start
npm run jaco:status

Setup installs the dependencies and builds the runtime. jaco:status reports what is actually ready, not what is meant to be.

Questions

What is JACO?

A local-first runtime for persistent, policy-bound and verifiable agent execution. It runs on your own machine and owns the execution state around whichever model you connect: goals, tools, policy, durable mission state, verification, receipts and restart continuity.

What do I need to run JACO?

Node.js 24 or newer. Run npm run setup, then npm run jaco:start, and check the result with npm run jaco:status.

How do I know an agent really did the work?

A claimed result needs a receipt or other observable evidence. Generated text or an attempted action is not accepted as proof, and an unknown outcome fails closed.

Can an agent spend money by itself?

No. External financial commitments require your explicit approval.
